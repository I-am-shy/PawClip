**文本选中的真相（浏览器实测才知道）**：此前 body 上已有
`user-select: none`，所以面板上其实**什么都选不中**——包括剪贴板正文。
用户要的是"只有内容可选"。修法：
- `.item-preview`（列表行正文摘要）与 `.preview-text`（预览正文）显式放开；
  `.filelink`（预览里的文件路径，也算内容）保留。
- body 与这几处都**同时写 user-select 和 -webkit-user-select**：Wails 用
  系统 WebView，macOS 12 及更早的 WebKit 只认前缀，少了会整条失效
  （表现为"什么都能选中"——很可能就是用户看到徽标/快捷键能选中的原因）。
- 控件（.badge/.quickkey/.item-meta/.item-trailing/.titlebar/.nav/
  .searchbar-*/.batchbar/.statcard/.btn/.iconbtn/.linkbtn）显式再写一遍
  none：不依赖 body 继承，将来谁在 .item 上放开选择也不会带坏它们。
- 实测（vite + agent-browser + 注入假 window.go 造数据）：
  从正文拖过徽标和快捷键 → 选中的只有正文；清空选区后从徽标/快捷键起拖
  → 什么都选不中。⚠️ 从"选不中"元素起拖时旧选区不会被清掉，必须先
  removeAllRanges 再测，否则会误判。

**本次最重要的工具教训**：对**同一个文件**在一个消息里并行发多个 Edit
会互相覆盖（各自读原始内容再写回，后写者赢）——本会话因此丢了至少 6 处
编辑且全部"报成功"。规则：**同一文件的多次修改必须逐条串行**；不同文件
可以并行。每轮批量编辑后必须 grep/读盘核对关键改动真的落盘了。
另：BSD grep 不支持 `\|` 交替（又踩了两次），复杂匹配用 Grep 工具。

后台进程教训：`(... npx vite ... &)` 随 Bash 工具的 shell 退出被杀，
curl 探活通过也没用；要长跑必须 run_in_background。

## 快捷键：录制式设置 + 提示与设置绑定（下午续）

用户反馈三点：设置读不到键盘输入（是纯文本框，要背 "CmdOrCtrl+Shift+V" 写法）、
提示与设置不绑定（搜索框占位写死 "⌘⇧V 呼出"）、没热键时提示不变。

实现（提交待记）：
- 新增 `frontend/src/hotkey.ts`：comboFromEvent（Keydown→规范组合串，用
  e.code 免受输入法影响；macOS ⌘→CmdOrCtrl、⌃→Ctrl，Win 反过来；只产出
  后端 ParseHotkey 认的记号）+ formatCombo（→⌘⇧V / Ctrl+Shift+V，空→""）。
- Settings 的 HotkeyInput：点一下读键盘，Backspace=清除、Esc=取消；
  录制中 preventDefault+stopPropagation（否则 ⌘, 会切视图）；keyup 也要吞
  （按钮 keyup 会发 click，而按钮已换成未录制态）。
- 占位提示：search.placeholder 拆两条（有无热键），App 用 formatCombo 从
  settings.ui.hotkey 现算传下去——提示从此是"算出来的"。
- 后端 `setHotkey`：ui.hotkey 走**先注册、后落库**的专属路径。清空=合法状态
  （UnregisterHotkey，不再误报"被占用"）；不合法组合直接拒绝不落库；
  被占用时先恢复旧热键再返回错误。writeSetting 从 SetSetting 抽出共用。
- attachPanel 先 ParseHotkey 校验库里的值，坏值降级为"本次不注册"并推
  提示——否则 default 分支直接 return，连托盘都不装（托盘是唯一退出入口）。
- i18n：新增 notify.hotkeyInvalid；App 的 'show'/'settings' 事件现在会弹
  note（启动期"热键被占用"以前被静默丢弃）。
- 契约测试 `hotkey_setting_test.go`：清空/不合法/被占用回滚 + 跨语言检查
  （Go 读 frontend/src/hotkey.ts 的全大写记号逐个喂 ParseHotkey——前端多写
  一个后端不认的键名会在提交时红，而不是用户按了没反应）。fakePanel 加
  attachCfg 记录与 hotkeyErrFor（按组合失败，才能测"新键失败旧键恢复"）。
- TestNoUnlocalizedUserFacingErrors 抓到了 jsonString 里的中文字面量 →
  按"前端契约违约、不可达"加 // diag: 标记。
- CSS 坑：.settings-row-wide .input {width:100%} 会把旁边"清除"挤成竖排，
  .hotkey-field 必须 width:auto 抵消、.btn 加 flex:none。
