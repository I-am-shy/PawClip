# 占位文件，不要删除。
#
# main.go 里有 `//go:embed all:frontend/dist`，embed 一个"不存在的目录"会直接
# 编译失败。本仓库把 Vite 产物全部 gitignore（见根目录 .gitignore），只保留
# frontend/dist/gitkeep 这个文件，保证：
#   1. 全新 clone（没跑过 npm）也能 `go build ./...` / `go test ./...` 通过；
#   2. `wails build` 会先执行 npm run build，把真实产物写进 dist 后再编译。
#
# 注意：Vite 的 build.emptyOutDir 每次都会把 frontend/dist 整个清空——
# 包括这个文件。所以 package.json 的 build 脚本在 vite build 之后会执行
# scripts/ensure-dist-placeholder.mjs 把它补回来，否则每构建一次仓库就多一个
# 删除记录。本文件（scripts/dist-placeholder.txt）是内容的唯一来源，dist 里的
# 那份是它的副本；要改内容请改这里。
